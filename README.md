# เงินออกยัง?

นับถอยหลังวันเงินเดือนออก บอกว่าวันนี้ใช้ได้อีกเท่าไหร่ พร้อมเพื่อนร่วมทุกข์ที่อารมณ์เปลี่ยนตามกระเป๋าตังค์

## ไฟล์ในโปรเจกต์

| ไฟล์ | ทำหน้าที่ |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด (UI, ตัวละคร, เสียง, การคำนวณ, การเก็บข้อมูล) |
| `manifest.json` | ทำให้กด "เพิ่มลงหน้าจอโฮม" แล้วเปิดเหมือนแอป |
| `sw.js` | ทำให้เปิดใช้แบบออฟไลน์ได้ |
| `icons/` | ไอคอนแอปและ favicon |
| `.nojekyll` | บอก GitHub Pages ไม่ต้องแปลงไฟล์ |

## ขึ้นเว็บด้วย GitHub Pages

1. สร้าง repository ใหม่ เช่น `payday` (ตั้งเป็น Public)
2. **Add file → Upload files** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในนี้ขึ้นไป แล้วกด **Commit changes**
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/payday/`

## อัปเดตเว็บ

1. อัปโหลดไฟล์ที่แก้ทับของเดิม
2. เปิด `sw.js` แล้วเปลี่ยน `payday-v1` เป็น `payday-v2` (เลขถัดไป) ทุกครั้ง ไม่อย่างนั้นบางเครื่องอาจยังเห็นเวอร์ชันเก่าจาก cache

## ข้อมูลผู้ใช้

- ข้อมูลทั้งหมด (งบ, รายจ่าย, ประวัติ) เก็บไว้ในเบราว์เซอร์ของเครื่องผู้ใช้เท่านั้น ไม่ได้ส่งไปที่ server ไหน
- ถ้าผู้ใช้ล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ หรือเปลี่ยนเครื่อง ข้อมูลจะหาย
- ปุ่ม "ลองดูอนาคต" ยังเปิดอยู่ ถ้าบันทึกรายจ่ายตอนกำลังดูอนาคต รายการจะถูกบันทึกเป็นวันที่ในอนาคตด้วย
